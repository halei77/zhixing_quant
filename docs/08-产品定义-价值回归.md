# 08 · 产品定义：价值回归策略（目标 3）

> **层级**：L2 规范 ｜ **前置阅读**：[03-测试策略](03-测试策略.md)、[04-数据质量门禁](04-数据质量门禁.md)、[01-路线图](01-路线图.md) ｜ **何时读我**：开发价值回归策略/股票池页面前；评审等级划分与回测结论时

## 一、定位

寻找**稳健**的价值回归介入点：股票因**短期情绪超跌**，但**基本面未受实质影响**，跌出了回归空间。

每日**盘后**从全市场筛出符合条件的股票，产出**当日股票池**（带等级），页面展示。

> 本文只定骨架。这是三个目标中细节最多、数据依赖最重的，细节在 Step 10 开工时按第七节 TBD 清单敲定。

## 二、核心概念

| 概念 | 定义 |
|---|---|
| 超跌 | 短期价格大幅下跌且主要由情绪驱动（量化定义 TBD） |
| 基本面未受损 | 排除业绩预亏 / ST / 重大利空等情形（判定规则 TBD，依赖财务数据源） |
| 介入点等级 | 由超跌程度 + 基本面多指标（含 Forward PE）**复合运算**得出：**D / C / B / A / SR / SSR**，SSR 最高（完整排序、是否含 S 级待确认） |
| 股票池 | 每日盘后全市场扫描产生的当日入选名单（带等级） |

## 三、功能

1. **每日盘后批处理**：全市场扫描 → 当日股票池 + 等级
2. **展示页面**（假设并入目标 1 站点，新增"股票池"页，复用部署与鉴权）：
   - 当日入选股票列表 + 等级
   - 每只票：**连续在池天数**、**历史入池时间记录**
   - 任意历史日期的池回溯
3. 与目标 1 联动（可选，低优先级）：对池内股票一键生成分析提示词

## 四、数据依赖（三目标中最重，故排最后）

- 全市场日线历史——**必须包含已退市股票**（见第五节）
- 财务指标：Forward PE 等外部成熟数据源（与目标 1 二期同源，Step 6）
- 基本面排除项所需数据（业绩预告/公告类，届时评估来源）

## 五、回测要求（用户硬性要求）

1. **大量回测**：等级划分与阈值必须经回测验证，不允许拍脑袋定级
2. **回测台账**（03-L4.5）：每次回测留痕；策略报告必须引用台账编号并披露"这是第几次回测"
3. **必须包含退市股票**（03-L4.6）：排除退市股 = 用事后存活信息筛选样本 = 变相未来函数；历史股票池必须按当时全市场成分还原
4. **数据源警示**：akshare 对退市股覆盖有限；04 文档闲鱼源审计的"幸存者偏差审计"条款是本项目的主战场；若最终数据仍不覆盖，回测报告必须**显著声明偏差范围与方向**（结果偏乐观）

## 六、验收标准（骨架，Step 10 开工前补全细节）

1. 每日盘后自动产出股票池 + 等级，页面可查当日与历史
2. 连续在池天数、历史入池记录正确且可复现
3. 等级计算管线通过 L4 全套测试（确定性、截断一致性、成本敏感性）+ 回测台账完整
4. 回测样本含退市股（或在报告中显著声明偏差）

## 七、TBD 清单（做时敲定，不阻塞定稿）

- "基本面未受损"的判定规则与所需字段

- 入池/出池规则、连续在池的统计口径（跨节假日、停牌如何处理）

## 八、明确不做
