# ADR-0014 · 有偿转接源接入位次

> **层级**：L3 决策档案 ｜ **前置阅读**：[ADR-0004](0004-数据源接入顺序.md)、[04 §五](../04-数据质量门禁.md) ｜ **何时读我**：接入或使用 rds/promax 转接数据前；想调整源顺序或退役某源时（变更须新建 ADR）

- 状态：Accepted（2026-09-21，用户拍板："补充进来吧" + 主动提供双源 key 文件，并授权无人值守推进）

## 背景

ADR-0004 定了三源顺序（akshare → 抓包源 → 闲鱼源），未包含有偿 Tushare 谱系转接源。Step 9 财务数据（目标 1 二期 Forward PE、目标 3 价值回归前置）在 akshare 侧验证后仍有硬缺口：FY1-FY3 盈利预期、远期 PE 原料、非标审计意见、股东户数历史、历史涨跌停价序列（缺口分析：`${ZX_DATA_ROOT}/reports/qoute-gap-analysis-2026-09-21.md`）。

废弃项目 Qoute 曾采购并实测过两家同谱系转接源，留下接口名册、量纲陷阱与限流纪律遗产（`reports/qoute-survey-2026-09-21.md`）。用户已从桌面取回两源 key，2026-09-21 实测：rds 200（datahubco 快照路径，返回含北交所当日数据）、promax 200（daily 通）。

## 决定

1. **源顺序修订为：akshare → {抓包源、有偿转接源} → 闲鱼源**。抓包源与转接源同为二级源、**同位次不排序**：风险特征与供给字段不同（抓包=行情 K 线类、免费维护重；转接=财务/状态类、付费稳定），互不替代互不阻塞；ADR-0004"任何时刻最多一个未驯服源"的爆炸半径原则不变——各自接入窗口内仍单源推进。闲鱼源仍居末位不变。
2. **现役两源分工**：rds（datahubco）首选——9 个本地快照接口族快路径；promax（mobcvb）备选——独有接口与广覆盖。429/503 按 1→5→30 分钟阶梯退避，首选源走不通切备选重试同一请求，断点不丢单（Qoute §7 纪律继承）。
3. **转接源只接日线级与财务/状态类数据**；分钟线维持 sina（ADR-0009），不从转接源抓分钟。
4. **每一张表独立验收**：04 §五 通用清单 + 有偿转接源专项全过，禁凭"同一家另一张表过了"放行。
5. **key 管理**：git 外 `~/zhixing_secrets/*.key`（chmod 600），禁入库/禁入聊天/禁入文档；工具经环境变量读路径，默认值不存在——没配就响（同 backup_dir 的理由）。

## 理由

Qoute 已替本项目付过一次学费：哪些接口能用、量纲坑在哪、限流怎么退避，全是实测记录，比从零选源少一步。双源 key 实测均存活，Step 9 最大的外部依赖（"财务数据源到位时间不可控"）随之消掉大半。但 Qoute 的废弃教训必须内化为本决定的一部分（见后果）。

## 后果

- **结构性警告（Qoute 废弃根因）**：多家转接源是同一上游镜像谱系，**源间数值一致不得作为健康证据引用**；独立锚点（akshare、腾讯公开样本、抓包源）保留且必须参与对账。
- 每月订阅成本由用户承担，续费与否用户定；key 失效 → 该源健康分掉线、相关 dataset 停更，不静默。
- 付费 ≠ 可信：每张表照旧过门禁，黄金样本、R 规则、专项审计一项不少。
- 抓取纪律承袭 Qoute §8：解析 `zip(fields,row)` 禁下标；null 禁 0 填充；字符串数字先 float()；只接实测可用清单内接口，新接口先最小验证；周线/月线量纲与日线不同（股/元、比率 vs 百分点），涨跌幅一律自算。
