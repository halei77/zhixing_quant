## 背景

用户 2026-09-24 点名三样：**1 分钟K、最新基本面、远期 PE**。ADR-0011 头注写明「改
`config/prompt_templates.yaml`、加数据组件……变更须新建 ADR」，所以三样里凡属新组件形态的，
都要先有一份档案再落代码。设计合成（三路只读调研的合成结论）已把三样的源与形态讨论定：

1. **最新基本面**是固定头——「页面提供任何类型的数据，都应该包含股票的最新基本面」。
   它不是模板的一个可选项，而每条模板（含 ADR-0017 自定义组合）的底座。
2. **forward_pe** 正源在 rds `fina_report_rc`（业绩预告 `forecast` 只能当降级旁路，
   06 §十-5 那句「原料 forecast」与此矛盾，见设计合成 §六.1，未裁决），本批次不实现，但形态要先钉。
3. **minute_1** 的 `ts` 语义与 `ex` 复权口径不钉死就会在源接入时各写各的（ADR-0009 的坑重演），
   实现也在另一个批次。

盘上已有、模板没挂的四张参考表（`daily_basic`/`forecast`/`stk_limit`/`index_daily` 的挂载）
走 ADR-0016 既定形态，本 ADR 只在决定 4 补齐其进模板的程序与大盘钉源。

## 决定

### 决定 1：`fundamental_head` 形态 = YAML `always_data` + CI 断言，不可取消

- **声明**：`config/prompt_templates.yaml` 顶层 `always_data` 列出固定头条目
  （`{dataset: fundamental_head, days: 1, fields: [close, total_mv, circ_mv, pe_ttm, pb,
  ps_ttm, dv_ttm, turnover_rate]}`）；`templates.parse` 装载时把它合并进**每条**模板的
  `data`（排最前）。模板侧没有排除语法——「不可取消」的机器形态就是合并 + 断言。
- **断言**：CI 测试判「每条 ready 模板**生效后**的 data 都含 `fundamental_head`」
  （06 §八-4 机器判定同款手法），并重放红路：删掉 `always_data` 键必须判红。
- **兜底**：直构 `Template`（自定义组合）不经装载，`prompt.build` 用代码注册表
  `templates.ALWAYS_DATA` 补同一颗头；YAML 与注册表逐项相等由漂移测试钉住。
  **不硬插正文**：补的是数据选择，取数照旧走逐段循环，空了照旧出 `NO_DATA_NOTE`
  （ADR-0020）——硬插会把「取数失败」变成组装层的隐式行为，这正是 ADR-0011 决定 4
  「指令头部由代码钉死、数据段走模板配置」的边界。
- **内容**（10–12 行，≈250–400 token）：名称/代码（`read_master()` listings）、
  收盘日期 + 收盘（`daily` 序列末行，**不复权**——ADR-0016 决定 5 两行口径各行其表）、
  总市值/流通市值（万元）、PE(TTM)/PB/PS(TTM)/股息率/换手率（`daily_basic` 末行）。
  null →「—」禁 0 填充；ROE/增速/行业**不做**（原料不在盘上）。口径行复用估值表那句
  （代码生成、模板删不掉），渲染是估值表家族的键值（两列）形态，共享表头字典与格式常量。
- **不落派生快照表**：快照 = 各序列在 as_of 的最新可见行，生成时现拼；落盘会造第二个
  「最新」事实源。
- **空**：`daily_basic` 那天没行 → 整节 `NO_DATA_NOTE`，不给只有表头的空表。

### 决定 2：`forward_pe` 形态骨架（本批次不实现，形态定在这）

- **逐日点时**：窗口内每交易日 `t` 的 `EPS_est(t)` 取**发布日 ≤ t** 的当时最新预测；
  **禁止**用 as_of 那天的预测回填全窗——那是把今天才知道的盈利预测递给 120 天前。
- 缺测写「—」，**不回落 pe_ttm**：两条不同定义的线接缝会被读成估值跳变。
- 与日K 同 `days`（同 `window()` ⇒ 天然同窗逐日对齐）；`fields: [close, fwd_pe,
  est_period, est_asof]`——`est_asof` 把点时可见性印在表里。
- **服务端现算、不落派生表**：落盘会把 as_of 钉死在回填那晚（壳不产生口径，docs/11 §六-2）。

### 决定 3：`minute_1` 的 `ts` 映射与 `ex` 口径（骨架，实现在另一个批次）

- **`ts` 映射显式钉死**（ADR-0009 决定 4：`ts` = K线**收盘**时刻）：ngw `times` 首根 09:30、
  午末 11:30、午后首 13:01、末根 14:59、**缺 15:00**——既非标准开点也非收点，逐段重标 +
  黄金样本钉死。
- **`ex` 取不复权**（空）：与 ADR-0009 决定 4「抓不复权、因子在日线」对齐；同一分钟干净区
  内不混复权语义。`count≥1500` 静默 0 行是显式分支，不当事后补丁。

### 决定 4：盘上已有的参考表按 ADR-0016 形态挂进模板

- `TABLE_DATASETS` 补 `stk_limit`（up_limit/down_limit）与 `index_daily`
  （OHLC + 量额），字段装载时按表校验；每表配自己的口径行（涨跌停=元不复权绝对价；
  指数=点位 + 量手/额千元，均来源转接源 rds）。
- 分策略挂载、`days` 与同模板日K同数（同窗对齐）；pending 模板同样先挂，
  转正时不再补。
- **大盘钉源**：`index_daily` 段读 `000001.SH`（上证指数），不是当前个股——六位代码空间
  重叠，不换 symbol 必读空；小标题印出「大盘（上证指数 000001.SH）」自证是哪条基准。

## 理由

用户 2026-09-24 点名三样，且「任何类型的数据都应包含最新基本面」把固定头定成了产品口径；
ADR-0011 头注要求加数据组件须新建 ADR，本档案即该程序性要求的兑现（含设计合成 §五.4 列的
「新 ADR 草稿」）。

## 代价

- **代价一（读名单的每次生成）**：固定头的名称现查 `read_master()`（组合根内、离线快照），
  每次生成多读几份小 CSV；换来的是与搜索同一份名单、不另立第二份答案。
- **代价二（YAML 与代码两处声明）**：`always_data` 与 `ALWAYS_DATA` 双份，靠漂移测试钉相等；
  测试红了说明有人只改了一边。
- **代价三（头永远在场）**：token 下限抬高 ≈300；分钟数据缺段的票上，提示词变成
  「头 + 日K + 交代段」的形状——交代段点名缺口（ADR-0020 代价一原样）。
- **代价四（大盘钉死一只指数）**：想要深成指/沪深300 做基准的模板要再改——当前形态
  `index_daily` 段没有"选哪只指数"的旋钮。

## 不做什么

- **不落 `fundamental_head` 派生表**（决定 1）、**不实现 `forward_pe`/`minute_1`**（决定 2/3
  只定形态，各在自己的批次里落地）。
- **不做 ROE/增速/行业**进头：原料不在盘上（设计合成 §五），不从训练记忆里补。
- **不放宽 ADR-0020**：头空也出交代、不给空表；全空照旧整条拒。
- **不动反幻觉固定头部**（`compose.ANTI_HALLUCINATION` 仍只有一份）。

## 回归条件

下列任一成立 → 新建 ADR 取代本 ADR 的对应决定：

1. 用户过目后要改固定头的字段、位置或不可取消性；
2. `forward_pe` 实现时发现逐日点时不可行（原料给不出发布日）；
3. `minute_1` 接入时 ngw `times` 语义与本档案决定 3 不符；
4. `always_data` 机制要演化成组件级必选/可选声明（与 ADR-0020 回归条件 1 汇合）。
