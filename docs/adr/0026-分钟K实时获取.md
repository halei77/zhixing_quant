# ADR-0026 · 分钟K实时获取：站点生成之路对分钟段放行联网

> **层级**：L3 决策档案 ｜ **前置阅读**：[ADR-0025](0025-分钟K去本地化.md)、[ADR-0012](0012-站点取数与组合根.md)、[ADR-0009](0009-分钟线源与存储布局.md)、[ADR-0024](0024-分钟线降级源与采集范围扩大.md) ｜ **何时读我**：改站点分钟数据路径、动实时抓取限速/缓存口径时

- 状态：Proposed（2026-09-25 起草；超时/限速参数待服务器实测定稿）
- 决策人：用户指令（ADR-0025「所有分钟K的需求都转为实时获取」）的实施面

## 背景

[ADR-0025](0025-分钟K去本地化.md) 撤掉了分钟K的本地化存储与发布，留下两个消费面的空洞：

1. **模板分钟段**：`短期投资`（60/30/5 分）、`波段`（60 分）与自定义组合的分钟条目在盘上必空
   ——过渡期出「本节无数据」交代（诚实但不是产品）。
2. **前端 K 线面板**：`/api/kline` 只有日线，分钟周期无从展示。

两条通路实测（2026-09-25，服务器首尔机房）：sina `stock_zh_a_minute` 通（1970 根到当日）、
ngw `dk/kline` 通（缺正规头 403、带 `HEADERS` 即 200）。降级机制（sina 空帧/异常→ngw 同周期，
`Grabbed(rows, via)` 行解析分派）已在 #64 交付并有全套离线测试——本 ADR 把它从「采集端」
搬到「站点端」。

ADR-0012 决定 2 的原纪律（生成之路不联网、站点只读发布副本）在分钟段被 ADR-0025 授权推翻；
其余 dataset 的纪律**不放宽**——日线/参考表仍读盘，混进实时路会把「站点数据可复现」整个丢掉。

## 决定（骨架，参数待实测回填）

### 决定 1：实时抓取层住 `site/live.py`，组合根装配

- 单一入口 `fetch_minute(code, period, days) -> list[Bar]`：sina 主 → 空帧/异常降级 ngw
  （复用 `sources/relay/client.KLINE_TYPES` 与 ngw/sina 适配器的行解析），返回**原始价 Bar**；
  复权按 ADR-0009 决定 4 现算：分钟价 × 当日日线因子（因子读盘上 daily，站点已有副本）。
- 装配在 `zx-site` 的 `main()`/`create_app`（ADR-0012 决定 1 的组合根纪律）：
  `prompt.build(..., minute_source=live.fetch_minute | None)`——**注入参数**，测试给假的，
  生产给活的；没给（None）分钟段退回「本节无数据」，与今天的过渡态一致。

### 决定 2：进程内 TTL 缓存 + 全局限速闸（公网免口令站点的自我保护）

- 站点已无鉴权（ADR-0019），实时抓取是**可被公网放大成 DDoS 转发器**的面——护栏是决定的一部分：
  - 缓存：`(code, period)` 键，TTL = 交易时段 90 s / 收盘后 1 h（同一分钟内重复生成零外发）；
  - 全局令牌桶：源请求 ≤ `RATE` 次/分钟（实测后定，初值 20/min），超限**排队不拒**，
    排队上限 N 秒后排不进 → 该段出交代（不 500、不假数据）；
  - 并发闸：同一时刻在途源请求 ≤ `CONC`（实测后定，初值 2），其余等待——sina 的封 IP 前科
    （坑 #11）与 ngw 的 Qoute 封禁史都指向同一句话：站点的突发必须被整形，不能直达源。
- 超时：单源请求 ≤ `TIMEOUT` s（sina 与 ngw 各一值，实测中位数 ×4 上界定），
  超时按"该源这次没给"走降级链，降级链穷尽 → 交代。

### 决定 3：深度口径——实时只服务「最近」，不冒充历史

- 模板分钟段：sina tail 1970 根（5 分≈41 日/30 分≈247 日/60 分≈493 日）与 ngw 单页 ≤1400 根
  都只够"最近"；`days` 请求超过实时深度时，按**实际取到的**出标题（决定 3 同款诚实），
  不做 start 翻页深挖——翻页深挖是回填工具（zx-minute）的职责，不是每次生成该干的事。
- `/api/kline` 加 `period` 参数（1/5/30/60，缺省 daily 不变）：前端分钟面板同一 live 入口。

### 决定 4：门禁与干净区不介入

实时数据**不过 gate、不落盘、不进健康分**——它是展示/提示词用的"现场行情"，
不是研究数据资产；要变成资产就回去跑 zx-minute 采干净区（那条路门禁齐全）。
`reports/` 记站点侧的抓取失败计数（进程内累计 + 日志），供运维看见源的健康度。

## 代价

- 生成延迟 +0.5~3 s（分钟段在链路里时）：模板含三个分钟段的 `短期投资` 最坏 +6~9 s——实测给数。
- 公网可打站点 → 源配额被消耗：限速闸兜底，但"闸内水位"是运维要盯的新面（docs/10 补）。
- 复权因子依赖盘上 daily 副本：日线停更时分钟实时段的复权口径会落后——与日线副本同责，
  发布链路的老问题，不在本 ADR 新增。

## 不做什么

- 不做服务器侧分钟落盘/预热缓存的全市场化（那是 ADR-0025 撤掉的东西换壳回来）。
- 不做 websocket 推送行情（站点是提示词工具，不是行情终端）。
- 不动非分钟 dataset 的离线路径（ADR-0012 决定 2 对其余条目原样有效）。
