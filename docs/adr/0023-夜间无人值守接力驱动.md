# ADR-0023 · 夜间无人值守接力驱动（一任务一全新会话 + 最小交接棒）

> **层级**：L3 决策档案 ｜ **前置阅读**：[05-AI协作章程](../05-AI协作章程.md)、[09-任务流水线与回测台账](../09-任务流水线与回测台账.md) §十、[README §5](../../README.md) ｜ **何时读我**：跑/改夜间驱动 `tools/night_driver.py`、改交接棒格式、质疑无人值守边界时（变更须新建 ADR）

- 状态：Accepted（2026-09-25，用户批准「夜间无人值守驱动 + 会话交接棒」实施计划即本 ADR 的采纳；机制交付后**何时开跑由用户定**）
- 决策人：用户拍板机制形态（外部驱动脚本 / 任务来源双模 / 只交付不自跑），agent 起草
- 关联：05 规则 7（自主范围不外推）、05 Q5（记忆边界）、09 §八（不登记即开工违规）、ADR-0007（产出物归档 reports/）、ADR-0014（`zx-relay` 是数据转接 CLI，与本机制无关）、任务 #63

## 背景

2026-09-24 夜班单会话连跑 17 小时：上下文只涨不掉（p50 246k、峰值 962k），25 次大文件
Read 灌入 4.27 MiB 后每轮请求都重读整窗，累计 **5.5 亿 cache-read token**，`/cost` 估价
$400（未知模型回退计价，真实花费另计）。用户的诉求是无人值守开发——「我定好任务就去
睡觉了，由 AI 决策开发什么」——同时「执行完一个任务就带着必要的内容去下一个会话」。

同会话内靠 `/compact` 只能缓解：自动压缩在大窗口下 ~90% 才触发，重读成本在此之前已经
付掉。要根治只有**换会话**：每个任务都是干净上下文，历史只通过一份小交接棒传递。

## 决定

### 决定 1：外部驱动循环，一任务一全新会话

`tools/night_driver.py` 每任务起一个全新无头 `claude -p` 会话；会话收工写交接棒后进程
退出，下个任务再起新进程。**禁止**把多个任务塞进一个长会话（上次夜班的形态）。

### 决定 2：交接棒（handoff）是跨会话唯一上下文载体，格式契约在 09 §十

≤150 行 / ≤8KB，六节强制（结论、关键决策、触碰文件、证据指针、开着的口子、建议下一
任务）。**只给指针不给内容**：不贴文件内容、对话史、完整日志。低风险自主决策按 05 规则 7
的披露口径记入「关键决策」（选了什么 / 为什么 / 代价）；Q1 四节点事项只进「待用户裁决」。
跨会话的长期事实照旧走文档/ADR/坑表（05 Q5），交接棒只承载「本批次」的最小状态。

### 决定 3：任务来源双模，Q1 四节点永不自动执行

用户给清单按清单跑；没给清单由驱动从 `zx-task board` + 01 路线图自主挑就绪任务。命中
人工门禁关键词（验收/采纳/黄金样本/合入/上线/策略启用/用户签字）或阶段已在功能验收及
以后的任务一律跳过挂起，进决策包。会话侧 `zx-task advance` 最多推进到**数据验证**；
`conclude` / `resume` / `abandon` 是用户裁决位，无人值守永不调用。

### 决定 4：无人值守权限档显式覆盖全局 bypassPermissions

用户全局 `~/.claude/settings.json` 是 `defaultMode: bypassPermissions`。夜班会话必须
`--permission-mode acceptEdits --settings tools/night/night-settings.json`：allow 白名单
只放行门禁命令、`git add/commit/push origin main`、`zx-task` 只读与推进；deny 显式封
`git push --force*`、`git reset --hard*`、`git clean*`、`git branch -D*`、`git push --delete*`
与 `tools/publish_site.sh`（发布留晨间人审，日常数据 cron 与本驱动无关）。仓库级
`.claude/settings.json` 同带这份 deny，顺带保护交互会话。

### 决定 5：命名用 handoff，不用 relay

`zx-relay` 是数据转接 CLI（ADR-0014）、`${ZX_DATA_ROOT}/reports/relay/` 已存回填日志。
交接棒落 `reports/night/<date>/handoff-NNN-<taskid>.md`，避免撞名。

## 代价

- **跨任务上下文为零**：任务边界、文件位置、口径都要靠简报与起手式重述，每任务多付一遍
  起手式开销（这是刻意买的小钱）。
- 驱动脚本自身是新维护面：超时、校验、报告聚合都可能出 bug；用假 claude 离线测试压住。
- 交接棒质量依赖会话自觉——驱动只做机器校验（行数/节头/破坏性命令痕迹），内容对不对
  仍要晨间人审。

## 不做什么

- 不做同会话自动 compact 调优（治标，见背景）。
- 不自动发布生产（`publish_site.sh` 在 deny 清单）、不动黄金样本、不采纳文档、不合并策略。
