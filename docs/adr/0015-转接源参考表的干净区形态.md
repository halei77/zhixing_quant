# ADR-0015 · 转接源参考表的干净区形态

> **层级**：L3 决策档案 ｜ **前置阅读**：[ADR-0014](0014-有偿转接源接入位次.md)、[04 §五](../04-数据质量门禁.md)、[ADR-0003](0003-存储方案.md) ｜ **何时读我**：把 forecast/fina_audit/stk_limit/daily_basic 等非行情表接进干净区前；想改参考表存储形态时（变更须新建 ADR）

- 状态：Accepted（2026-09-22，用户无人值守授权下起草并执行；ADR-0014 决定 4"逐表独立验收"的载体）

## 背景

ADR-0014 定了转接源只接"日线级与财务/状态类"数据，但干净区的现有形状（ADR-0003 + `layout.DatasetSpec`）是 **Bar 中心**的：`store_bars` 收 `Bar`、门禁 R 规则判 OHLC 量价、`query.read_bars` 出 K 线。转接源的表（stk_limit 涨跌停价、daily_basic 估值、forecast 业绩预告、fina_audit 审计意见……）不是 K 线——硬塞进 `Bar` 契约是削足适履，为此泛化 `store_bars` 又要动 Step 3 的承重墙。

第一张表 stk_limit 另有一个口径陷阱：引擎吃**后复权**价（ADR-0010 决定 9），而 stk_limit 给的是**不复权**绝对价——除权日直接比对会错位。它的正确用法是导出**精确涨跌幅**（交易所四舍五入后的真实档位，如 9.97% 而非 10.5%+容差），这在两种口径下不变。

## 决定

1. **形态**：每张转接表 = 干净区一个**参考表 dataset**（`data/<表名>/year=…/symbol=…`，与 ADR-0007 分区形状一致），行是**该表自己的模型**（NamedTuple，与干净区 `Record` 同风格——`partition.read` 按位置构造，pydantic 进不了这个路径）；解析与校验在 `sources/relay/tables.py`，不进 `Bar` 契约。
2. **存储**：独立的通用表读写件（`storage/tables.py`），复用 `layout.partition` 原语与按名投影，幂等语义与 `store_bars` 相同（同键同值不写、同键异值修复、跨批冲突抛）。`store_bars` **一字不动**。
3. **验收**（ADR-0014 决定 4 的逐表落地，04 §五 转接专项）：R 规则引擎不适用于非行情行，每张表配**表级校验器**——字段完备（缺列整批拒）、值域（如 up_limit > down_limit > 0）、主键唯一（冲突抛不裁决）、**锚点对账**（与干净区已有的同口径数据抽样互核：stk_limit 的涨跌幅对日线昨收，偏差超 R004 档位 + 1pp 即整批拒）。
4. **黄金样本**：与行情源同一机制——真实响应快照落 `${ZX_DATA_ROOT}/golden/`，采纳进 `tests/golden/` 需用户批准（Q1-③）；CI 里离线重放。
5. **抓取**：`sources/relay/client.py` 一个客户端（GET + `X-API-Key`，key 走 `config.relay_key_dir`），限流退避 1→5→30 分钟、rds 首选 promax 备选切源重试（ADR-0014 决定 2）；CLI 入口 `zx-relay`，报告归档 `reports/relay/`。
6. **消费方**按需自取（经 `storage.tables.read_table`），第一阶段不做回测板查表的接线——stk_limit 对引擎的正确馈送方式（精确档位 pct + 后复权换算）单独立项，不在本 ADR 顺手做。

## 理由

- 参考表与 K 线的**写入口径、校验判据、读出形状**三样全不同，共用的是分区布局与幂等语义——按"共享的进 layout、不同的各自立"切，比泛化 `store_bars` 的改动面小一个数量级，且不给 Bar 契约开"非行情行也能混进来"的口子。
- 锚点对账复用干净区已有的日线（akshare），同一上游镜像的两家转接源互验不算证据（ADR-0014 后果），akshare 才是锚。

## 后果

- 每接一张表：`tables.py` 加行模型 + 校验器 + 测试 + 黄金样本采样，走一遍 04 §五 转接专项清单；没有"批量豁免"。
- 干净区从此有两类 dataset（行情 Bar / 参考表），`storage.query.read_bars` 对参考表抛错而不是返回空——类型混淆在这里就响。
- 参考表同样进备份、进健康日报的覆盖面声明。
