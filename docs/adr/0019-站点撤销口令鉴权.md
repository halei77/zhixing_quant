# ADR-0019 · 站点撤销口令鉴权

> **层级**：L3 决策档案 ｜ **前置阅读**：[ADR-0013](0013-站点壳的搜索与鉴权.md)、[ADR-0018](0018-前端技术栈选型.md)、[06-产品定义-提示词站点](../06-产品定义-提示词站点.md) ｜ **何时读我**：改站点鉴权、加 `/api/*` 端点、或有人提议"把口令加回来"时（变更须新建 ADR）

- 状态：Accepted（2026-09-24，用户指令"去掉口令限制"）
- 决策人：用户
- 关联：ADR-0013 决定 3 与代价五/六（被本 ADR 取代）、ADR-0018 决定 4 的"X-Token 头鉴权"半句（被本 ADR 取代）、06 §二/§八-6

## 背景

ADR-0013 决定 3 定过 fail-closed 的口令鉴权：`ZX_SITE_TOKEN` 没配就起不来、`/api/*` 一律要
`X-Token`、`secrets.compare_digest` 逐字节比。理由写在那里——站点在公网上、口令只有一个、
"部署成功"与"裸奔"的日志同形。

2026-09-24 用户指令："去掉口令限制，然后提交推送部署到服务器。" 这是对该决策的显式撤销，
属产品口径变更，按 README §三"ADR 只增不改"新建本 ADR，不改 ADR-0013 正文。

用户画像没变（06 §二：本人自用、无多用户/权限体系需求），变的是对"公网裸奔"这个代价的取舍：
用户接受它，换来的是打开 URL 即用、不再有口令要记要填。

## 决定

### 决定 1：服务端不再有口令概念

- `site/api.py` 删除鉴权中间件、`site_token()`、`TOKEN_ENV`、`_authorized()`；`create_app`
  不再收 `token` 参数。
- `ZX_SITE_TOKEN` 环境变量**无人读取**：配了不报错也不生效；没配照常启动（fail-open 是
  这次的意图本身，不是实现走样）。
- 全部路由、任何来源，不回 `401`/`403`。拒绝只来自业务（404 认不出票 / 400 拒绝生成 / 422
  请求体不合法 / 500 程序错），语义见 zx-site 契约，一条不改。

### 决定 2：残留的口令痕迹一律"无视"，不是"报错"

- 服务端**无视**请求里的 `X-Token` 头与 `?token=` 查询参数，响应与不带时逐字节一致。
  理由：新旧前端并存期（ADR-0018 后果二）里，浏览器缓存的旧 JS 还会继续发这些字段；正确
  行为是当它们不存在。401 会让部署窗口期的用户对着一个"明明填对了还被拒"的页面。
- 两套壳（`frontend/` 与旧 `site/static/`）删除口令输入框、口令存储（localStorage/
  sessionStorage）与 `X-Token` 拼装；`Zx_SITE_TOKEN` 相关的 e2e 环境变量一并移除。
- 连接点（dot）语义变为"最近一次 boot/请求成功"，不再是"口令接上了"。

### 决定 3：回归鉴权的条件

站点要给第二个人用、或要挡住爬虫/滥扫时，回归鉴权 = **新建 ADR**（先于代码），
不得直接把本节删掉或往回接。ADR-0013 决定 3 的全部理由在那时原样有效。

## 代价

- **代价一：公网任何知道 URL 的人都能用站点**——搜字典、读K线、生成提示词、写/顶掉最近
  搜索留痕（`recent.json`，cap 10，无鉴权写）。数据本身是从公开行情汇总的，泄露面是"这个
  站点存在 + 用户在看哪些票"，用户 2026-09-24 明示接受。
- **代价二：无滥用防护**。扫到 URL 的爬虫可以把生成接口当免费算力用，把留痕刷成自己的。
  缓解暂无（限流不在一期范围）；发现滥用时按决定 3 回归鉴权。
- **代价三：ADR-0013 代价五/六随口令一并失效**（明文口令、浏览器口令副本），但那两条是
  "有口令时"的代价，不是收益——撤销它们不代表获得了什么新安全属性。

## 一句话

**口令整体撤销：服务不认、页面不问、残留痕迹无视；要加回来得先写一份新 ADR。**
