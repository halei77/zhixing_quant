# ADR-0016 · 估值组件进提示词的口径

> **层级**：L3 决策档案 ｜ **前置阅读**：[ADR-0011](0011-提示词组装的口径.md)、[ADR-0015](0015-转接源参考表的干净区形态.md)、[06 §四/§五](../06-产品定义-提示词站点.md) ｜ **何时读我**：给提示词模板加参考表类数据组件前；质疑估值表的单位与空值处理时（变更须新建 ADR）

- 状态：Accepted（2026-09-22，用户无人值守授权；依据同 ADR-0014/0015）

## 背景

ADR-0011 把提示词的数据组件定为 Bar 形（`dataset+days+fields+adjust`），一期只有K线。"长期投资"/"建仓价分析"两条模板因此 pending。ADR-0015 之后，干净区有了第一张参考表 daily_basic（pe/pe_ttm/pb/ps_ttm/dv_ttm/total_mv/circ_mv/turnover_rate，rds 逐日），估值序列具备了进提示词的数据条件。

## 决定

1. **组件形态**：模板 data 条目新增参考表类——`dataset` 名命中参考表注册表（`daily_basic`）即走表路径，`days` 语义不变（交易日），`fields` 从该表自己的字段清单里选（模板装载时按 dataset 类别校验，选错当场拒）。`adjust` 对参考表**无意义**：估值指标是比率与金额，不存在复权；表路径忽略它并用自己的口径行。
2. **单位与口径行**（决定 3 的延伸，表的一部分）：估值表的口径行写明"不复权收盘；pe/pb/ps 为倍数，dv_ttm 为 %，total_mv/circ_mv 为**万元**，来源转接源 rds"。单位是源给的，注释跟着源走，不由模板作者改写。
3. **空值**：源给 null 的格子渲染为 **"—"**，并在口径行声明 "'—' 表示源未提供"。这不是偷懒——银行/保险的估值科目大面积 null，0 填充会把"没这数"洗成"这数为 0"，大模型会拿它做算术（ADR-0015 解析器已禁 0 填充，这里是同一纪律的渲染侧）。
4. **模板状态**：`长期投资` 翻 ready（估值序列已够它 output 文本的规则运转）；`建仓价分析` 保持 pending（它要 earnings/PE 序列的"分母"语义，现有数据撑不起，waiting_on 如实写）。
5. **行情快照引用**：估值行里的 close 是**不复权收盘**，与 K线表的后复权价并存于同一条提示词时，两行口径各行其表——大模型对不上的那部分由反幻觉头部约束"不许出现表中没有的数字"。

## 理由

估值是"基本面未受损"判定的第一块拼图（08 的 D~SSR 分级要 Forward PE），也是目标 1 二期在路线图上的承诺。daily_basic 先到，就先让估值序列说话；ROE/增速/三大表等 A 桶组件按同一形态逐个接入，每张表走一遍 ADR-0015 的验收，不在这里预支。

## 后果

- 模板装载的 fields 校验从"单一清单"变成"按 dataset 类别"，`templates.py` 的 fail-closed 面变大——测试跟着铺。
- 参考表组件渲染不经过 `domain.bar`，`table.py` 出现第二套渲染入口（K线表 / 估值表），共享表头字典与格式常量。
- forecast（事件型）与三大表（A 桶）后续按同形态接入，每张一验；本 ADR 不预支它们的渲染细节。
