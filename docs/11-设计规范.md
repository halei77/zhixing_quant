# 11 · 设计规范（Liquid Glass Design System）

> **层级**：L2c 设计规范 ｜ **前置阅读**：[06-产品定义-提示词站点](06-产品定义-提示词站点.md)、[ADR-0013](adr/0013-站点壳的搜索与鉴权.md) ｜ **何时读我**：改站点任何前端（HTML/CSS/JS）、新增页面、评审 UI 时

状态：✅ **已采纳（2026-09-23，用户授权）**。

**动机（2026-09-23 实测）**：现手写版被量成"扁平 + 全站同一种材质 + 无投影 + 一屏 5 层
模糊 + 表单控件回落 Arial"，读起来不是毛玻璃。本规范按"**清晰的 iOS 27 毛玻璃、中性白灰**"
重定。前端改用 Vue 3 + Vite 见 [ADR-0018](adr/0018-前端技术栈选型.md)。

`frontend/src/style.css` 的 `:root` 是本表的**实现**——改本表必须同一
commit 改 CSS（02 §七：文档与受它约束的代码原子生效）。**数值真值在本表**，CSS 不得私自另立一套。

## 一、设计原则（冲突时按序取舍）

1. **内容优先**：数据、K线、提示词正文是主角；玻璃只做容器与交互，不做装饰。
2. **空间分层**：内容层实、交互层透、浮层层级分明。**玻璃不叠玻璃**。
3. **克制材质**：一屏同时最多 **3 层**背景模糊；能用实底就不上玻璃。
4. **语义色彩**：红涨绿跌只用于行情；交互强调色独立，**不与涨跌语义混淆**。
5. **动效服从**：动效只解释层级变化，不做表演；尊重 `prefers-reduced-motion`。

**反目标（不是这些）**：扁平化（flat）、普通半透明卡片、纯装饰的"毛玻璃模板"。目标是有
**厚度、高光、前后层次**的清晰毛玻璃——玻璃要看得出来是一块玻璃，而不是背景提亮了一点。

## 二、空间层级（本规范的核心）

```
z 层            材质             用途
─────────────────────────────────────────────────────────────
z-30 浮层       glass-float      dialog / dropdown / tooltip / toast
z-20 交互层     glass-float      抽屉、面板、浮起卡片（承载正文的卡片走 z-0 实底）
z-10 骨架层     glass-chrome     nav / toolbar / sidebar / tab bar
z-0  内容层     surface-solid    K线、提示词正文、表格、代码 —— 一律实底
z-(-1) 背景      ambient         底色 + 两团环境光晕（不承载任何可读内容）
```

**硬规则**：正文与数字永远落在**内容层**（实底），不许直接铺在玻璃上。玻璃上只放
标题、标签、控件、短标签值。理由：`backdrop-filter` 会随背后内容变化而压对比度，
长文本放在玻璃上等于把可读性交给运气。

## 三、Design Tokens

> 命名 `--zx-<类别>-<角色>`；下表数值为**规范值**，深色/浅色两套。

### 3.1 颜色

| token | 深色 | 浅色 | 用途 |
|---|---|---|---|
| `--zx-bg` | `#050608` | `#F2F2F7` | 页面底色 |
| `--zx-ambient-1` | `rgba(213,69,60,.10)` | `rgba(213,69,60,.06)` | 环境光晕（暖） |
| `--zx-ambient-2` | `rgba(31,169,122,.08)` | `rgba(31,169,122,.05)` | 环境光晕（冷） |
| `--zx-text` | `#F5F5F7` | `#1C1C1E` | 主文本 |
| `--zx-text-2` | `#A1A1AA` | `#6B7280` | 次文本 |
| `--zx-text-3` | `#6B7280` | `#9CA3AF` | 弱文本/占位 |
| `--zx-ink` | `#F5F5F7` | `#1C1C1E` | 主色（按钮/强调，中性近白/近黑） |
| `--zx-ink-contrast` | `#0B0E14` | `#FFFFFF` | 主色上的文字 |
| `--zx-focus` | `#93A4BC` | `#5B6472` | 焦点环（唯一带一点色，只为可见性） |
| `--zx-up` | `#FF453A` | `#D70015` | **A股红涨** |
| `--zx-down` | `#30D158` | `#1A8A4A` | **A股绿跌** |
| `--zx-warn` | `#FF9F0A` | `#B26A00` | 警告（token 超限等） |
| `--zx-seal` | `#D5453C` | `#D5453C` | 品牌印章（**仅 logo**） |

**决定（2026-09-23 用户口径）**：整体走**中性白灰**——不引入品牌色，主按钮/强调用中性
主色（深色底=近白、浅色底=近黑），红绿只留给涨跌。焦点环是唯一保留的一点灰蓝，纯粹为
无障碍可见性，不作装饰。**"清晰的 iOS 27 毛玻璃"是目标，"扁平化"是明确的反目标。**

### 3.2 玻璃材质（三档）

| token | 深色底 | 浅色底 | 模糊 |
|---|---|---|---|
| `--zx-glass-chrome` | `rgba(255,255,255,.08)` | `rgba(255,255,255,.68)` | `blur(30px) saturate(180%)` |
| `--zx-glass-float` | `rgba(255,255,255,.12)` | `rgba(255,255,255,.80)` | `blur(28px) saturate(180%)` |
| `--zx-glass-inset` | `rgba(255,255,255,.05)` | `rgba(15,23,42,.05)` | `blur(12px) saturate(140%)` |
| `--zx-surface-solid` | `rgba(9,10,14,.80)` | `rgba(255,255,255,.96)` | 无（内容层） |
| `--zx-stroke` | `rgba(255,255,255,.16)` | `rgba(15,23,42,.10)` | 1px 描边 |
| `--zx-stroke-hi` | `rgba(255,255,255,.40)` | `rgba(255,255,255,.95)` | 顶边高光（inset） |
| `--zx-sheen` | `linear-gradient(180deg, rgba(255,255,255,.14), rgba(255,255,255,0) 42%)` | 同 | 玻璃表面高光层（`::before`） |

**玻璃要"看得出"，靠三样**：底色与背景的对比 + 顶边高光 + 分层投影。缺任何一样，都会读成
扁平。三样都是硬要求，不是可选装饰。

**背景必须"有东西可折射"**：纯色/近黑背景上，`backdrop-filter` 等于没做（2026-09-23 实测：
背景纯黑时，加了模糊的卡片仍被读成"不透光的实色块"）。背景要有多点柔光晕（明暗或低饱和
色块）+ 细噪点纹理，玻璃才读得出磨砂。这是本规范里最容易被漏掉的一条。

### 3.3 圆角 / 间距 / 阴影

| token | 值 | 用途 |
|---|---|---|
| `--zx-r-xs` / `sm` / `md` / `lg` / `xl` / `pill` | `8 / 12 / 16 / 20 / 28 / 999` px | 控件→卡片→大面板→胶囊 |
| `--zx-sp-1..8` | `4 / 8 / 12 / 16 / 20 / 24 / 32 / 40` px | 4pt 栅格 |
| `--zx-shadow-chrome` | `inset 0 1px 0 rgba(255,255,255,.06), 0 8px 24px rgba(0,0,0,.28)` | 吸顶条 |
| `--zx-shadow-float` | `inset 0 1px 0 var(--zx-stroke-hi), 0 16px 40px rgba(0,0,0,.38), 0 2px 8px rgba(0,0,0,.22)` | 浮层 |
| `--zx-ring` | `0 0 0 3px color-mix(in srgb, var(--zx-focus) 60%, transparent)` | 焦点环 |

### 3.4 字体

- 字族：`-apple-system, "SF Pro Text", "PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei", sans-serif`；等宽 `ui-monospace, "SF Mono", Menlo, monospace`。
- 阶梯（size/line）：`display 34/41 · title1 28/34 · title2 22/28 · title3 20/25 · body 17/24 · subhead 15/20 · caption 13/18`。
- 字重：`400 / 500 / 600 / 700`，标题 600–700，正文 400。
- **数字一律 `font-variant-numeric: tabular-nums`**（价格、涨跌幅、量、token 数）——数字跳动时列不抖。
- **表单控件必须显式继承字族**：`input, button, select, textarea { font: inherit }`——否则浏览器回落 Arial（现状缺陷）。

### 3.5 动效

| token | 值 | 用途 |
|---|---|---|
| `--zx-dur-1` / `2` / `3` | `120ms / 200ms / 320ms` | 微交互 / 标准 / 入场 |
| `--zx-ease` | `cubic-bezier(.2,.8,.2,1)` | 默认（Apple 式先快后缓） |
| `--zx-ease-out` | `cubic-bezier(0,0,.2,1)` | 退场 |

只允许动 `opacity` 与 `transform`；**禁止动画 `backdrop-filter`**（逐帧重算模糊）。

## 四、核心组件（材质档 / 圆角 / 状态）

| 组件 | 材质档 | 圆角 | 关键状态 |
|---|---|---|---|
| Navigation / Toolbar（吸顶条） | chrome | 无（贴边） | 滚动时底边描边显现 |
| Sidebar | chrome | lg | 选中项用 `glass-inset` + accent 竖条 |
| Tab | inset 轨道 | pill | 选中滑块 `glass-float` + 阴影，滑动过渡 |
| Dialog | float | xl | 背后遮罩 `rgba(0,0,0,.35)` + 背景模糊 |
| Button 主 | ink 实底 | lg | hover 提亮/压暗 4%，active `scale(.97)`，disabled 45% |
| Button 次 / Ghost | float / 透明 | lg | hover 抬描边 |
| Input | inset | md | focus 出 `--zx-ring`，内阴影 |
| Card | solid | lg | 内容容器默认实底（§二）；只有真正浮起的卡片用 float，顶边高光 |
| Dropdown / Menu | float | lg | 从触发点缩放淡入（`transform-origin` 对齐） |
| Tooltip | float | sm | 180ms 延迟出现，纯文字无箭头装饰 |
| Toast / Status | float | lg | 底部居中，3s 自动消失 |

## 五、无障碍与性能（硬约束）

- **对比度**：主文本对底 ≥ 4.5:1；次文本 ≥ 3:1；强调色上的文字必须实测达标。
- **焦点可见**：所有可交互元素 `:focus-visible` 出 `--zx-ring`，不许 `outline:none` 了事。
- **命中区** ≥ 44×44px（移动端）。
- **降级**：`prefers-reduced-motion: reduce` → 全部过渡/动画关闭；
  `prefers-reduced-transparency: reduce` 或浏览器不支持 `backdrop-filter` → 玻璃档退化为
  `--zx-surface-solid`（可读性优先于观感）。
- **模糊预算**：同屏 ≤ 3 层 `backdrop-filter`；不嵌套玻璃。
- 长列表/长正文用 `content-visibility: auto`。

## 六、实现契约（不许破的既有约定）

1. **前端形态**：Vue 3 + Vite（源码 `frontend/`，构建产物 `frontend/dist` 由站点发），组件基础
   shadcn-vue（Radix Vue + Tailwind）——原「零构建静态三件套」已由 [ADR-0018](adr/0018-前端技术栈选型.md) 取代。
2. **壳不产生口径**（ADR-0013 决定 5）：JS 里不许有格式化、单位换算、天数推导；页面上
   每个数字都读自 `/api/*`。
3. **外部文字只当文本渲染，绝不拼 HTML**（防 XSS）：旧壳 `site/static/app.js` 由
   `test_the_page_writes_text_and_never_markup` 钉，Vue 侧由 `test_the_vue_shell_writes_text_and_never_markup`
   钉 `frontend/src` 不许出现 `v-html` / `innerHTML`。
4. **不引外部字体/图标库**：系统字族 + 内联 SVG。
5. 静态件 `Cache-Control: no-cache`（运维手册）。

## 七、样板与自检

- 样板页 = 站点单页 `frontend/src/App.vue`（本项目当前唯一页面）。
- 每次改完 UI，**必须用浏览器实际渲染并截图**核对，不许只看代码判断。
- 收尾自检句：**"这像 Apple Liquid Glass 的空间感，还是普通的半透明卡片？"**
  答不上"像"，就继续调——重点看：内容层与玻璃层是否分得开、边缘是否有高光与层次、
  动效是否解释层级、玻璃是否只在交互层。
