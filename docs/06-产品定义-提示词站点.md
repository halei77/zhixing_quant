# 06 · 产品定义：提示词生成站点（目标 1）

> **层级**：L2 规范 ｜ **前置阅读**：[00-项目宪章](00-项目宪章.md)、[01-路线图](01-路线图.md) ｜ **何时读我**：开发站点任何功能前；评审站点功能边界时

## 一、定位

一句话：**可信数据打包机**——把质量门禁后的股票数据，按模板组装成大模型提示词。

解决两个问题：

1. **LLM 幻觉**：大模型凭训练记忆报股价/财务数字，不可靠 → 提示词内嵌真实数据 + 反幻觉指令
2. **爬取数据异常**：数据一律取自门禁后的干净区，不取自实时爬取

用户不在站点上阅读数据本身（数据是给大模型看的），站点只做**选择、组装、复制**。

**只生成提示词，不接入任何大模型 API**——复制后由用户自行粘贴到目标大模型使用。

## 二、用户与部署

- 用户：本人自用，无多用户/权限体系需求
- 部署：阿里云轻量服务器，公网访问，无口令鉴权（固定口令于 2026-09-24 按用户指令撤销，[ADR-0019](adr/0019-站点撤销口令鉴权.md)）；家里 WSL2 与阿里云的职责划分见 [ADR-0006](adr/0006-部署架构.md)
- 技术形态（实现层决策，可逆）：Python FastAPI + 轻量前端；无实时推送；日K图用轻量图表库

## 三、核心流程

```
搜索股票 → 选数据组件（或选模板自动带出组件组合）→ 生成提示词 → 预览 → 一键复制 → 粘贴至任意大模型
```

## 四、功能组件

### 一期

| 组件 | 说明 |
|---|---|
| 股票搜索 | 代码/名称/拼音模糊搜索 |
| 搜索留痕 | 最近搜索股票列表，上限 10 只；输入第 11 只时淘汰最早一只（FIFO）；服务端持久化，刷新/重开不丢 |
| 基本信息 | 名称、代码、行业、总市值/流通市值、最新价、涨跌幅（取自干净区） |
| K线组件 | 周期：日K / 60分 / 30分 / 5分；每周期独立选天数；字段可选（OHLC/量/额/换手率） |
| 模板引擎 | 见第五节，配置驱动 |
| 提示词生成 | 组装 → 预览 → 一键复制；实时 token 估算显示；超阈值警告 |
| 日K图展示 | 低优先级，锦上添花，没有不影响主流程 |

### 二期（项目中期，依赖外部财务数据到位）

| 组件 | 说明 |
|---|---|
| 财务数据组件 | Forward PE（用户从外部获取成熟数据）为核心示例，另含 PE(TTM)/PB/PS 历史序列、ROE、营收/净利增速、分红等——"相对重要的数据都应可输出为成型提示词"；清单二期细化，每个字段接入必过 04 门禁与审计。**进展（2026-09-22）**：估值序列已落地（[ADR-0016](adr/0016-估值组件进提示词的口径.md)，PE(TTM)/PB/PS/股息率/市值日度序列进「长期投资」模板，来源转接源 daily_basic）；**ROE/营收净利增速已落地（2026-09-25）**：`fina_trend` 逐日点时序列进「长期投资」与「建仓价分析」，来源转接源 **`rds fina_indicator`**（`ann_date` 即首披日，可点时）——**A 桶 akshare 不可用**：新浪接口无发布日、东财「最新公告日期」实测 30 组只有 12 组是首披日（gap 344–379 天），都做不了点时。**Forward PE 已落地（2026-09-25）**：逐日点时序列进「短期投资 120 / 波段 250 / 长期投资 250」，与同模板日K **同窗同长**（[ADR-0022](adr/0022-基本面固定头与派生组件形态.md) 决定 2），来源转接源 **`report_rc`**（研报预测 EPS，`report_date` 即发布日）——**不是** `forecast`：后者是业绩预告（净利上下限），只能当降级旁路，两张表同名不同物 |
| 更多模板 | 配置化，随时增改 |
| 最新消息组件（候选） | 新闻/公告类；akshare 新闻接口质量待评估，评估后再定去留与分期 |
| MCP 接口（候选） | 站点能力以 MCP 协议暴露给大模型直接调用（生成提示词/查询数据）；协议与鉴权届时评估 |

## 五、模板系统（配置驱动）

**模板 = 一套数据源选择逻辑 + 一整套提示词结构**（角色 / 任务 / 输出要求），YAML 配置文件承载，改配置即生效，禁止改代码。

初版模板（默认组合均为草案值，可随时调整）：

| 模板 | 默认数据组合 | 任务概述 |
|---|---|---|
| 短期投资 | 120天日K + 60天60分K + 30天30分K + 10天5分K | 1-4 周机会与风险：趋势、量价、支撑压力 |
| 波段 | 250天日K + 90天60分K | 数周至数月的波段结构与买卖区域 |
| 长期投资 | 750天日K + 财务数据（二期） | 估值水平与基本面趋势 |
| 建仓价分析 | 250天日K + 财务数据（二期） | 合理建仓区间测算 |
| 最新消息解读 | 消息组件（候选）+ 30天日K | 消息面对走势的影响 |

> 模板清单未最终定稿——配置化的意义就在于随时调整。

## 六、提示词规范

### 固定头部（所有模板强制）

- 角色设定（如"你是资深 A 股分析师"）
- **反幻觉指令**：只允许使用本提示词内提供的数据；禁止使用训练记忆中的任何股价/财务数字；所需数据未提供时必须明确说明

### K线格式（已定）

- **默认 Markdown 表格**：LLM 解析友好度最高（用户授权选定"大模型理解最优解"）
- 备选 CSV 紧凑模式：模板级配置项，token 紧张时启用
- 不做 JSON（token 浪费严重）
- 时间正序排列（便于趋势阅读）；价格 2 位小数，量额取整
- token 预算参考：短期投资模板默认组合 ≈ 1080 根K线 ≈ 2 万 token

## 七、数据约束（不变量）

1. **进提示词的核心数据只读干净区**（04 关键不变量在站点侧同样成立）；站点辅助性数据（如搜索字典）可在阿里云直调 akshare——允许直调的清单在 Step 5 细化（ADR-0006），进提示词的数据一律不在其列
2. akshare 为主数据源；自研源（APP 抓包 / 购买数据）仅用于**补充 akshare 缺失字段**，接入走 04 第五节清单
3. 二期外部财务数据源（Forward PE 等）入库前必过门禁 + 审计；若其接入顺序与 ADR-0004 冲突，须先修订 ADR 再接入。
   **已按此执行（2026-09-25）**：`report_rc` 走完 04 §五 转接专项（独立锚点 2344 组、pooled 98.17%；分页守卫两族分流并有对抗测试），**点时可见性由逐日对齐 + 17 条未来函数对抗测试钉住**

## 八、一期验收标准

1. 全流程可用：搜索 → 选模板 → 生成 → 预览 → 一键复制
2. 模板 YAML 修改后生效，无需改代码
3. 生成提示词中的数据与干净区抽样比对 100% 一致（自动化对照测试进 CI）
4. 所有模板输出均含反幻觉固定头部
5. token 估算实时显示，超阈值（默认 10 万）警告
6. 部署至阿里云，公网可访问（原"有鉴权"验收项随口令撤销作废，[ADR-0019](adr/0019-站点撤销口令鉴权.md)）

## 九、一期明确不做

多股票对比 / 实时行情推送 / 用户系统 / 复杂图表 / 大模型 API 接入（只生成提示词，不代调用）/ 策略回测功能（属目标 2/3）
